# Grid Exercise 1 — Fixed Track Layout

Lay out a header, menu, content, and footer using a basic two-row grid with mixed column sizes.

## Requirements

- Set up the grid with the following tracks: columns `10% 2fr 1fr`, rows `150px 1fr`.
- Make the header span the full width and pin the remaining areas to their respective tracks (menu in column 1, content in column 2, footer in column 3).
- Keep the spacing consistent with a `gap` and ensure the layout fills the viewport height so the proportions are visible.
