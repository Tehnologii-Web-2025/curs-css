# Workshop CSS — Hoinarind prin lume 🌍

## Obiectiv

Veți învața cum să aplicați CSS pas cu pas pe un site static semantic (fără Flex/Grid).

## Fisiere de start

- HTML complet (index, about, contact)
- CSS-urile goale (le completăm împreună)
- Imagini organizate în `/assets/img/...`

## Ce veți face

1. Veți lucra în `styles/global.css` mai întâi (reset, culori, font, nav).
2. Apoi stilizează paginile:
   - `home.css` → .hero, .destination, .tips
   - `about.css` → .page, .credits
   - `contact.css` → .page, .contact-form, .btn, .contact-info
3. Testați site-ul în browser și micșorează fereastra (mobile-first).

## Regulă de aur

Nu modificăm HTML-ul, doar adăugăm CSS.
